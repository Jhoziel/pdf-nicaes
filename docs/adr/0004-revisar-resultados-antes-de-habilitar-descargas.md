# Revisar resultados con atención antes de habilitar descargas

Cuando un resultado contenga páginas sin Código TRUSS identificable o reemplazos de combinación, la aplicación mantendrá la misma ejecución en una revisión de resultado antes de mostrar 100 % o habilitar artefactos descargables. El colaborador revisará evidencia visual local, resolverá cada página mediante asignación manual de TRUSS o conservación explícita sin identificar y confirmará los reemplazos; después, la aplicación recalculará los paquetes PCL afectados, aplicará estrictamente los conflictos y validará la integridad compartida antes de fijar un resultado inmutable. Esta decisión amplía ADR-0002: una revisión posterior a la confirmación inicia otra ejecución, los fallos de evidencia bloquean el resultado y el diagnóstico conserva únicamente conteos agregados sin códigos ni asociaciones de páginas.
